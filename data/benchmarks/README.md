# Benchmark data

Đặt dữ liệu benchmark tải về trong thư mục con riêng theo tên bộ dữ liệu, ví dụ `scholl-1993/`. Ghi nguồn, phiên bản, giấy phép và checksum trong `docs/DATASET.md`; mỗi bộ dữ liệu có thể có README và manifest checksum riêng. Không commit corpus tải về nếu kích thước hoặc điều khoản sử dụng không phù hợp; lưu script tải/chuyển đổi và hướng dẫn để tái lập thay thế.
